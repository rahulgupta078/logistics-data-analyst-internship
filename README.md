# Logistics Data Analyst Internship

This repository contains my work and projects completed during my Logistics Data Analyst Internship at YuvaIntern.

## Internship Overview

- **Role:** Logistics Data Analyst Intern
- **Organization:** YuvaIntern
- **Duration:** 4 Weeks
- **Mode:** Remote
- **Focus:** Logistics Data Analysis, Python, Data Cleaning, Visualization, Predictive Analysis and Optimization

## Projects

### Week 1 — Strategic Planning and Data Exploration
- Defined a logistics business scenario
- Identified relevant logistics KPIs
- Researched a public supply-chain dataset
- Planned the data-analysis workflow
- Identified suitable data science techniques

### Week 2 — Data Collection, Cleaning & Preprocessing
- Collected and inspected a public supply-chain dataset
- Analyzed data quality
- Checked missing values and duplicate records
- Performed missing-value handling
- Detected potential outliers using IQR
- Prepared numerical data for normalization
- Created a cleaned analysis workflow using Python and pandas
