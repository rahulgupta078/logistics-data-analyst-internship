# Week 2 — Data Collection, Cleaning & Preprocessing

## Internship
Logistics Data Analyst Internship — YuvaIntern

## Objective
The objective of this task was to collect, inspect, clean, and preprocess a public logistics dataset for further data analysis.

## Dataset
**Dataset:** DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS

The dataset contains supply-chain and logistics-related information including order, shipping, delivery, sales, and operational data.

The dataset was used to perform practical data preprocessing using Python and pandas.

## Work Performed

- Loaded and inspected the dataset
- Checked dataset dimensions and data types
- Identified missing values
- Checked for duplicate records
- Performed missing-value handling
- Detected potential outliers using the IQR method
- Applied Min-Max normalization to selected numerical variables
- Created a cleaned dataset for further analysis

## Dataset Statistics

- **Records:** 180,519
- **Columns:** 53
- **Missing values:** 336,209 cells
- **Duplicate rows:** 0
